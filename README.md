# OpenMRS-WebAutomation

## Project Name
OpenMRS-WebAutomation

## Description
OpenMRS-WebAutomation is a web automation testing framework designed for testing the OpenMRS website. This framework aims to facilitate automated testing processes, ensuring the reliability and functionality of the application.

## Installation Instructions
To get started with this project, you need to have the following:

1. **Java 17**: Ensure that Java 17 is installed on your machine.
2. **Set JAVA_HOME**: Make sure to set the `JAVA_HOME` environment variable to the location of your Java 17 installation.

## Run Command
To run the tests, use the following command:

```bash
./gradlew test
